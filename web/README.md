# Web Demo

หน้าเว็บสำหรับนำเสนอ: แสดงแอนิเมชันการทำงานของ judge ทีละขั้น
(compile → fork → setrlimit → seccomp → execve → running → wait4 → verdict)

## วิธีใช้

**โหมดจำลอง** ไม่ต้องมี backend: ดับเบิลคลิกเปิด `web/index.html` ในเบราว์เซอร์ได้เลย

**โหมด Live** เรียก `./judge` ตัวจริง (ต้องรันบน Linux / WSL):

```bash
make            # build ./judge
make demo       # = python3 web/server.py → เปิด http://localhost:8000
```

ถ้า server ติดต่อได้ หน้าเว็บจะสลับเป็นโหมด Live ให้เองอัตโนมัติ ในโหมดนี้แก้โค้ดในช่องซ้ายแล้วกดรันได้

## ฟีเจอร์สำหรับการนำเสนอ

| ปุ่ม / คีย์ | ใช้ทำอะไร |
|---|---|
| `Enter` | รัน |
| `Space` | หยุดชั่วคราว / เล่นต่อ (ใช้ตอนอธิบายแต่ละขั้น) |
| `R` | รีเซ็ต |
| 0.5× / 1× / 2× | ความเร็วแอนิเมชัน |
| **ถ้าไม่มี sandbox** | เปิดแล้วรันตัวอย่างเดิม เพื่อดูว่าถ้าไม่มีกรงเครื่องจะพังอย่างไร (ใช้ได้เฉพาะโหมดจำลอง) |
| สว่าง / มืด | สลับธีม (ใช้ธีมสว่างถ้าโปรเจคเตอร์ภาพจาง) |

## ไฟล์

- `index.html` — หน้าเว็บทั้งหมด (HTML/CSS/JS ไฟล์เดียว)
- `server.py` — server เล็ก ๆ ใช้แค่ standard library ของ Python
  - `GET /api/health`
  - `GET /api/examples` — ส่งโค้ดจาก `tests/attacks/`
  - `POST /api/judge` — รัน `./judge --json`

> ⚠ server รันโค้ดที่ส่งเข้ามาจริง จึง bind ไว้ที่ `127.0.0.1` เท่านั้น
